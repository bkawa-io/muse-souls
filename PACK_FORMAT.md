# Character folder format

Each directory under [`souls/`](souls/) contains:

- `SOUL.md`: the name-neutral ongoing personality, with 13 example replies. Examples illustrate voice, not real completed actions.
- `IDENTITY.md`: exactly **Name**, **Character**, **Vibe**, and **Emoji**; the distributed Name is blank.
- `NAMES.md`: optional suggestions, never permission to rename the user's assistant.
- `card.png`: the approved full-size illustration used for the character.
- `avatar-reference.png`: an approved square reference portrait, not an installed avatar.

Installation steps live only in the root [`INSTRUCTIONS.md`](INSTRUCTIONS.md). The website generates the copyable invitation from that template and the chosen character's file URLs. No character ZIPs are maintained.

The installation is proposal-first: permission before writing files, verified restorable backups before changes, optional names, and separate avatar-generation and avatar-setting approvals.
